# Article editor and builder UI compatibility research

Research date: 2026-09-15. Resolution context for [Assess editorcn and shadcn compatibility with the offline builder](https://github.com/dobrerares/student-org-site-builder/issues/99), within [Wayfinder: Articles and a redesigned builder](https://github.com/dobrerares/student-org-site-builder/issues/96).

## Finding and evidence limits

A familiar toolbar is feasible with editorcn/Tiptap, but it is **not a verified drop-in replacement**. Framework compatibility, archival CSS packaging, stored content, images and history need explicit integration decisions. This is source/documentation research: no integration, performance measurement, accessibility audit or runtime test was performed. No stack or product choice is made here.

Builder evidence is pinned to [revision 30d1cbd](https://github.com/dobrerares/student-org-site-builder/tree/30d1cbd70fef668773df0915f7f563f600dfc858); editorcn evidence to [revision b8b03a1](https://github.com/shadcn-labs/editorcn/tree/b8b03a18c15d74c3ba0345f9375332f6b870a2b5). Live documentation was inspected on the research date.

## Existing constraints

The editor uses Preact 10, Preact hooks/JSX and testing-library. Browser development uses Vite 6 with explicit Preact JSX and no React aliases in its configuration. Electron depends on the same editor package. [Editor manifest](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/editor-app/package.json), [Vite configuration](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/browser-shell/vite.config.ts), [Electron manifest](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/electron-shell/package.json).

Archival compilation is a separate esbuild path targeting ES2022/Preact. Its runner takes the first output as JavaScript and supplies only `bundle.js` to the inliner. It does not compile Tailwind or collect generated CSS. The inliner supports local styles supplied in its asset map, but passes external URLs through and does not recursively bundle CSS `url()` resources. Therefore a shadcn Vite plugin alone cannot complete archival packaging. [Runner](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/browser-shell/scripts/run-archival-build.ts), [inliner](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/browser-shell/src/archival/build-archival.ts).

ADR 0034 deliberately stores a narrow Markdown subset: escaped text, allowlisted links, h2–h4, no images/raw HTML, textarea input. Its prior WYSIWYG exclusion now needs reconsideration. A toolbar does not itself imply replacing every existing Markdown field. The pure renderer serves Node builds and browser previews. Custom HTML has a separate DOMPurify boundary; that is not proof that arbitrary rich-text output is safe. [Markdown ADR](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/docs/adr/0034-markdown-subset-and-richtext-block.md), [determinism ADR](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/docs/adr/0032-renderer-skeleton-and-determinism.md), [sanitizer policy](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/renderer/src/sanitize-config.ts).

## editorcn support and maintenance

The toolbar package declares React/React DOM `^18 || ^19`, Base UI `^1.0.0`, Tiptap peers `>=3.0.0 <4`, Lucide React and tailwind-merge. It uses React hooks and Tiptap React subscriptions. This is a **Base UI** implementation; it is inaccurate to assume all shadcn-derived controls use Radix. [Package manifest](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/package.json), [control source](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/src/controls/rte-control.tsx).

Getting-started instructions require Tailwind v4/shadcn globals, imported before editor CSS, and offer registry source copying or npm installation. **Documentation drift:** that page says Tiptap v2 or v3, but the inspected package peers require v3. Pin a coherent artifact and extension set before testing. [Getting-started source](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/apps/web/content/docs/getting-started.mdx).

The classic toolbar exposes bold, italic, h1–h6, lists, links, blockquote, undo/redo and other controls. The consumer supplies the Tiptap editor/extensions. Its toolbar export has no built-in image control; demos add one separately. Controls do not settle the permitted article schema. [Toolbar export](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/src/rte-text-editor.tsx), [image demo](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/apps/web/src/components/customization/static-renderer-demo.tsx).

Maintenance evidence is recent but short: repository metadata reported creation on June 22, 2026, a September 14 push, not archived, and no GitHub Releases. The checked-in changelog contains an August 26 initial release and September 11 JSON static-renderer work. This establishes activity, not stability or guaranteed support. A filename search found no test/spec files in the inspected checkout; unpublished testing is unknown. ## Styling, offline use and accessibility

shadcn's Vite guide adds Tailwind compilation and aliases; theme variables include background/foreground, primary, border and radius. editorcn consumes these plus its prose CSS. Compile/embed all selected assets for every shell. Keep builder styling separate from article/public-theme output. Audit selected fonts/icons/embeds for external requests; an online demo is not evidence of offline compatibility. [Vite guide](https://ui.shadcn.com/docs/installation/vite), [theming](https://ui.shadcn.com/docs/theming), [editor CSS](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/src/style.css).

Base UI documents keyboard, focus and ARIA support while leaving visible focus, naming and contrast to consumers. Radix provides similar primitive-level support if selected for builder components. Neither certifies the composed editor. editorcn controls have labels/pressed state, but its toolbar wrapper is a plain `div` without toolbar role or arrow-key navigation in that component. Keyboard travel, dialog focus return, selection retention, IME, screen-reader formatting state, mobile overflow and reduced motion remain untested. [Base UI accessibility](https://base-ui.com/react/overview/accessibility), [Radix accessibility](https://www.radix-ui.com/primitives/docs/overview/accessibility), [toolbar source](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/src/rte-toolbar.tsx).

## Content, assets, rendering and history

**Storage:** Tiptap provides HTML/JSON persistence and recommends JSON. editorcn exposes that document, not an Article/Site schema. Define versioned allowed nodes/marks and handling of unknown data. Markdown requires a bounded round-trip mapping because the existing subset lacks images, underline and arbitrary styling. HTML requires explicit import/render sanitization; JSON also requires attribute/URL validation. [Tiptap persistence](https://tiptap.dev/docs/editor/core-concepts/persistence), [editorcn serialization](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/apps/web/content/docs/editor/serialization-format.mdx), [Markdown ADR](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/docs/adr/0034-markdown-subset-and-richtext-block.md).

**Images:** editorcn's demo prompt reads local files as data URLs, then the demo calls `setImage`. This bypasses the builder's hash/VFS/AssetRef pipeline. A production adapter needs durable references, alt text, byte import/export, preview URL resolution and missing-asset behavior. Session blob URLs must not be stored as durable article references. [Image prompt](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/apps/web/src/components/image-prompt.tsx), [asset pipeline](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/assets/src/pipeline.ts), [asset picker contract](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/docs/adr/0044-no-technical-field-escape-hatches.md).

**Static rendering:** Tiptap offers DOM-free JSON-to-HTML rendering without an editor instance, using extensions/custom mappings. It also has mapping APIs without ProseMirror dependencies. This is a promising shared Node/browser path, but byte-identical output, image resolution and URL safety are untested. Editor node views do not automatically define static output. The approach does not require shipping an editing runtime to readers. [Static renderer documentation](https://tiptap.dev/docs/editor/api/utilities/static-renderer).

**Undo/import/export:** the current global Ctrl/Cmd+Z listener prevents default and invokes site history without a contenteditable exclusion or `defaultPrevented` check. Form edits feed site snapshots; ZIP import resets history. Tiptap controls introduce another history owner. Decide typing-versus-site undo behavior and synchronization before integration. Test typing → formatting → article/page switch → undo, import with an editor mounted, and export immediately after composition. Avoid document/editor feedback loops, lost selection and stale buffered exports. These are source-derived risks, not reproduced bugs. [Builder implementation](https://github.com/dobrerares/student-org-site-builder/blob/30d1cbd70fef668773df0915f7f563f600dfc858/packages/editor-app/src/editor-app.tsx), [Tiptap toolbar commands](https://github.com/shadcn-labs/editorcn/blob/b8b03a18c15d74c3ba0345f9375332f6b870a2b5/packages/editor/src/controls/rte-controls.tsx).
